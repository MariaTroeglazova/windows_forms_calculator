# Задание:
Разработать графическое приложение «Калькулятор» с использованием Windows Forms, позволяющее выполнять основные математические операции с помощью графического интерфейса.

### Требования:
1. Использовать Windows Forms, классы, методы, элементы графического интерфейса и обработчики событий. Реализовать математические операции с использованием принципов объектно-ориентированного программирования. Обеспечить проверку корректности вводимых данных и обработку математических ошибок.

2. Создать проект Windows Forms на языке C#.

3. Разработать главную форму приложения, содержащую поле для отображения чисел и результатов вычислений.

4. Добавить кнопки для ввода цифр от 0 до 9, десятичного разделителя и математических операций.

5. Реализовать четыре основные математические операции и инжинерные функции (cos, sin, возведение в степень, корень).

6. Реализовать кнопку  для выполнения вычислений и отображения результата.

7. Добавить кнопку для полного сброса текущих вычислений.

8. Реализовать удаление последнего введённого символа.

9. Добавить возможность выполнения последовательных вычислений без сброса результата.

10. Реализовать изменение знака текущего числа .
